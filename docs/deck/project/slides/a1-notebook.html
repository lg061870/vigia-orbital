github.com/lg061870/vigia-orbital

If you want to check any number, run it yourself. This is the actual notebook in Google Colab. The first cell controls the run: PUBLISH is False, so re-running saves nothing and simply compares the results with our official run, and the seed is fixed, so the same data gives the same numbers. The second cell downloads our data straight from the public GitHub repository and prints the exact data version it used. The QR code opens it. It goes step by step from raw NASA data to the forecast, uses only open data, and the same functions power the daily system. Link: https://colab.research.google.com/github/lg061870/vigia-orbital/blob/main/notebooks/vigia_orbital_modelo.ipynb
