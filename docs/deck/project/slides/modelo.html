logit(risk) = β₀ + β₁·History + β₂·Weather + β₃·Vegetation + β₄·Recent fire + β₅·Terrain · logistic regression, maximum likelihood (Newton–Raphson)

How does the model think? Like a weather forecaster. It starts from history: in a normal year, what’s the chance of fire in this canton at this time of year? For Liberia on the 23rd of January, 45 percent. Then it adjusts for today’s conditions compared with normal. Weather drier than normal multiplies the odds by 1.68 for each standard deviation. Vegetation greener than normal lowers them, times 0.79. Fire nearby in the last week raises them, times 1.16. And terrain, surprisingly, adds nothing at canton level — its effect is already in the history. The result is a probability from 0 to 1 for each of the next five days. Under the hood it’s a logistic regression, estimated by maximum likelihood with our own Newton–Raphson code and verified with a standard library. The multipliers shown are from the main five-day model (final coefficients, 2012–2025); the Liberia example uses the day-5 model, trained without 2018.
