# Vigía Orbital API

5-day fire-risk forecast for the cantons of Guanacaste, Costa Rica, computed on request from harmonized
NASA MODIS/VIIRS hot spots, NASA POWER weather and MODIS vegetation indices. NASA Space Apps 2026.
